## 项目愿景

建立"认知基础设施"_将复杂世界翻译成人能理解的结构.核心目标:知识平民化、通俗化,把专业术语翻译成日常用语,反对语言障碍与权威壁垒.

核心洞察:不是词条数量,而是"发现不同领域在重复同一种结构".例如控制论的"负反馈"、经济学的"市场调节"、生物的"内稳态",本质都属于"系统自稳定".

### 四大模块

1. **科学不装(同物异名网站)**:把专业术语翻译成"说人话",覆盖 10 大学科,已收录 977 个词条
2. **概念抗体**:三步还原法(物理/数学/权利还原),识别五类忽悠,引导认知升级
3. **行业分析**:认知地图、看门狗经济学、鬼话拆解、检测工具
4. **岗位拆解**:已收录约 26 个高薪岗位 SOP,降低职业信息黑箱

### 数据库现状（重要）

- **当前**：SQLite（better-sqlite3）是**唯一真相源**，所有词条/学科/图谱关系的权威数据都在这里。
- **Neo4j 图数据库已放弃,不再启用**：核心洞察是"发现不同领域在重复同一种结构"，本质是一张跨学科的概念关系网，这一洞察不依赖特定数据库。`data/neo4j/` 目录已删除；原残留的 `db/图数据库.js`、`services/图数据库服务.js`、`routes/图数据库.js`、`db/全量迁移到Neo4j.js` 与 `npm run sync:neo4j` 命令已于 2026-09-21 删除。
- **知识图谱接口不依赖 Neo4j**：`/api/v1/graph/nodes`、`/api/v1/graph/links` 由 `services/知识图谱.js` 直接 SELECT SQLite 的 `词条` 与 `图谱关系` 表，是**已生效的实现**。
- **Meilisearch 未启用**：`backend/bin/meilisearch.exe` 已删除，无需任何外部搜索服务。`services/Meilisearch服务.js` 读取 `MEILI_HOST`（默认 `http://localhost:7700`）做可用性探测，探测失败即自动回退到 SQLite `LIKE` 查询。

> 落地进度：应用只有一个 SQLite 数据层，数据目录 `data/` 由容器整目录 bind 挂载到 `/data`（含 `-wal`/`-shm`），WAL 未 checkpoint 的数据不会丢；**三本 `.db` 由 Git 跟踪，Git 里那一份就是它们目前唯一的退路**（`.gitignore` 第 61 行 `*.db` 把库全挡在外面，第 76-78 行 `!data/同物异名.db`／`!data/学科词库.db`／`!data/语义词典.db` 是三行精确白名单；`.gitattributes` 对这三本命中 `binary`，实测 `git check-attr binary` 为 `set`、`text` 为 `unset`）。这条在 2026-09-25 反转过一次：当天上午定的是"库不进 Git、待 `git rm --cached` 摘除"，当晚定稿改回纳管，判据是**唯一人工写入源在本机**——三本词库是人工整理出来的，丢了没有第二份。⇒ **不要对这三本执行 `git rm --cached`，也不要删那三行白名单**；删掉之后库文件再怎么写都不会脏工作区，等于静默丢掉唯一的兜底。纳管成立的前提有四条，缺一条就要重判：`.gitattributes` 的 `binary` 命中（否则二进制会被换行符改写）、提交进仓库的那份 `-wal` 必须是 0 字节、`git pull` 前先跑漂移哨兵（`compose/tools/db-drift-sentinel.sh`）、服务器侧禁用 `git reset --hard`/`checkout --` 覆盖库。需要快照时以 Git 那一份为准——服务器 `/root/db-backup-*` 与本机 `files/` 下的库副本已于 2026-09-26 全部清空，文件级备份一个不剩。接入层单轨：**Docker Compose + Caddy 反向代理**（站1 服务名 `twym`，compose 与 Caddyfile 在本仓库之外的编排仓库 `E:\website`，服务器上是 `/var/www`），HTTPS 由根 `.env` 的 `COMPOSE_PROFILES=https` 门控启用，证书自动签发与续期。旧栈（Nginx + 阿里云手动证书 + PM2）已作废，文档与配置均已删除，需回看走 Git 历史。

## 社区协作机制

采用三层协作机制,支持开放式内容共建:

| 层级 | 机制 | 说明 |
|------|------|------|
| 第一层 | 学科映射管理 API（`/api/v1/community/mapping*`） | 管理19个词库分表到核心学科的映射关系（实测 19 行、覆盖 8 个核心学科）；更新/删除两条路由因中文路径参数名恒 404，已于 2026-09-21 删除 |
| 第二层 | 词条纠错建议 API（`/api/v1/community/suggestions*`） | 用户可提交词条纠错、补充建议,管理员审核后生效 |
| 第三层 | Obsidian 内容协作 | 基于 Obsidian 的双向链接笔记系统,管理端写库后由 `services/Obsidian同步.js` 自动回写 Markdown,也可手动触发全量同步 |

相关接口:
- `POST /api/v1/admin/sync-obsidian` — 数据库全量同步到 Obsidian（需 `x-admin-token`）
